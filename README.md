# أداة تصعيد بلاغات الصحة العامة ومسارات الاستجابة السريعة
Public Health Notification Escalation & Rapid Response Pathways Tool

**آخر تحديث:** 30 أكتوبر 2026 — إعداد: د. حوراء الخليفة، إدارة مكافحة العدوى بالقطاع الشرقي

## المحتوى
- **التبويب الأساسي – التصعيد ومسار الاستجابة السريعة:** اختيار المرض ← مختصر التصعيد (د١ / د٢) ← اختيار الحالة (مشتبهة / مؤكدة) ← التفاصيل:
  - **الدليل الأول:** خطة التأهب والاستجابة للأمراض المعدية – وقاية، الإصدار 1، أغسطس 2026 (ملحق 1: قائمة الإبلاغ لمركز أحداث الصحة العامة)، مع مستوى التأهب ومعايير التصعيد العامة (خانات اختيار).
  - **الدليل الثاني:** قائمة أمراض مسار تفعيل فرق الاستجابة السريعة لمكافحة العدوى – وقاية 2026 (مباشر / عن بُعد / مشروط مع مؤشرات التصعيد).
- **التبويب المساند – احتياطات العزل:** CDC Appendix A (آخر تحديث 11 سبتمبر 2026).
